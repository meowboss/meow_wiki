# 身份与版本化内容阶段交付

日期：2026-11-12。此记录对应实际已验证的阶段，不代表市场/AI/上线加固已完成。

## 已落地

- Better Auth标准邮箱注册/登录/退出；Fastify桥接多cookie；数据库会话撤销，宿主HMAC绑定CSRF，来源/Host/绝对URL守卫。
- 默认server session模式，非生产持久随机secret，production要求显式密钥。客户端IP由Fastify可信remoteAddress覆盖专用头，不采信客户端伪造转发信息。
- 多空间列表/创建/设置，owner过滤与上限。用户/空间切换重挂载，清空旧编辑与问答等状态，未保存确认。
- 页面独立revision与历史、expectedRevision CAS、软删除恢复、父页防环。旧JSON迁移；父页删除使活直接子页脱离为根并递增版本。
- 插件同步资源清理、失败回滚、依赖卸载拒绝；当前不支持异步setup或异步disposer，不声称热重载。

## 实际证据

- 集成后单元/API/仓储测试53/53通过（其中部分仍为未整合服务实验测试）。
- TypeScript严格检查与生产Vite构建通过。
- Playwright使用本机Edge，真实注册→新建→两次保存→刷新→历史查看→删除→恢复→创建/切换第二空间→切回原页→退出通过，未产生pageerror。
- 浏览器首次运行发现退出按钮被侧栏布局挤出viewport，修复侧栏滚动/伸缩后重测通过；不是通过force click掩盖。
- Chromium下载停滞后取消，使用已安装Edge；测试不依赖未完成下载。

## 限制

尚未提供邮件找回、OIDC、自助账号删除、完整审计/限流配额、多人协作与生产安全审计。管理员不会通过抢注或注册参数获得角色，正式host管理入口在市场模块补充。历史M0 local数据不会自动转给首个注册者，避免错误归属；迁移认领应另有受信部署操作。
