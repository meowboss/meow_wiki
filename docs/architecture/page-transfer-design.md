# 页面包传输设计

> 文档性质：设计/边界文档：可能含早期目标与原型现状，是否已实现须查当前状态。 [当前状态](<../status/current-status.md>) · [知识库入口](<../README.md>)

2026-11-12。导出当前活跃页面(title/markdown/parentId/id)与空间名称说明，版本format meow.pages.v1。不是完整账号备份：不含历史/附件/插件安装/密钥/用户权限；历史另有完整JSON导出，库恢复用backup工具。

导入为追加，统一生成新UUID，重映射包内parentId；不信任源ID取得覆盖权，不修改目标空间元数据。拒绝重复ID、缺父引用、循环、未知字段及超过100页/5MiB包；单页沿现长度限制。一次Store.change事务，目标空间总量与历史预算也生效，失败全回滚。

内部Markdown链接重写、附件引用及跨包链接尚未实现；旧字符串ID仅作为包内映射键，不作为宿主路径或SQL片段。默认只读/追加避免不可逆覆盖。导出可以用来检查/迁移，但没有自称兼容任意外部Wiki产品。
