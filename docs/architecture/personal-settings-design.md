# 个人设置首批

> 文档性质：设计/边界文档：可能含早期目标与原型现状，是否已实现须查当前状态。 [当前状态](<../status/current-status.md>) · [知识库入口](<../README.md>)

查看真实账户资料与修改显示昵称，左下用户区与右上头像统一入口。邮箱/角色/账号ID/创建时间只读；没有邮件验证流程就不允许在此改邮箱，不伪造验证状态。头像使用本地昵称首字符，不引入外部头像跟踪URL。

GET/PATCH /api/profile使用真实session身份，PATCH额外CSRF，strict只允许name且trim1..80。返回公开白名单不返回密码/会话/Provider Key。更新同步应用会话显示，不重新挂载账号/空间或推进编辑基线。local/token非平台账号模式明确提示。

UI未保存昵称有dirty守卫；失败保留输入，不自动重试或刷新丢草稿。测试覆盖跨用户、角色注入、未登录、持久化和再次登录。首批不含邮箱修改、密码找回或任意图片上传。
