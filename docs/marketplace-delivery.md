# 组件首页与审核市场阶段验收

日期：2026-11-12。

## 已实现

- 组件草稿与不可变发布快照分离；更新expectedVersion CAS，新版本重新提交。
- 首页支持私有/已安装发行版组合、排序/删除、revision CAS；未知或不可访问引用占位。
- block仅markdown.text、page-list.title、search.title；动态数据来自使用者当前空间，Markdown走宿主净化，不执行用户脚本。
- 审核工作台使用真实会话admin角色；禁止作者自审；批准/退回/撤架并写审计。local/token身份不能审核。
- host CLI：`pnpm exec tsx src/admin.ts grant <已注册邮箱>` / `revoke`，MEOW_DATABASE指定同一数据库。CLI不创建新用户、不公开授予权限。
- 市场仅上架published release，安装固定快照。撤架禁止新安装，既有安装保留。
- M0私有模板幂等迁移；旧catalog不会未经新审核自动上架。

## 验证证据

全套61/61单元/API/仓储测试通过；TypeScript+生产构建通过；依赖审计未报告已知漏洞。

两条真实Edge浏览器用例通过：
1. 注册、页面两次保存、刷新、历史、回收站恢复、多空间隔离/切回、注销。
2. 私有声明式组件创建、添加到首页、保存与刷新后持久显示。

审核发布链路通过真实BetterAuth会话API测试：作者/审核员/安装者、越权、角色撤销、固定快照、布局CAS、撤架。尚未为三身份审核全过程编写浏览器E2E，不将API覆盖说成完整视觉验证。

## 新增但未完成的知识阶段

来源服务与HTTP支持导入文本、显式处理、版本化分块、检索引用、删除撤回；模型broker有上下文/输出/并发/超时限制、禁止重定向与引用编号检查。此时尚无资料管理UI，未配置真实模型、无真实provider质量评测、无AI提议确认或持久后台worker。宿主模型endpoint为部署受信配置，不接收用户任意URL；这不是通用SSRF沙箱。模型编号检查不证明语义上证据支持结论。

## 未完成

邮件恢复/OIDC、附件与导出、链接反链、模型真实配置评测、AI proposal、在线备份恢复、全局配额与公网部署加固仍待后续。已完成阶段不代表整体平台完成。
