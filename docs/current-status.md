# 当前能力与未完成项（交付核查）

2026-11-12。本文优先于历史阶段文档的状态描述；设计目标不等于已实现。

## 已实现并有本地证据

- 邮箱注册/登录/注销、数据库会话、CSRF、双用户资源scope与多空间。
- Markdown安全渲染、页面revision/CAS、历史恢复、软删除、防环父页规则。
- 声明式组件（文本/页面列表/搜索）、私有草稿、不可变审核release、安装固定快照、首页layout CAS。
- 宿主CLI管理员grant/revoke、禁止自审、批准/退回/撤架与审计。
- 文本来源导入/版本化处理/分块/关键词引用检索、删除撤回、账号配额。
- 模型broker固定宿主endpoint、超时/输出/并发限制、引用编号验证；可生成pending提议，人工确认时验证证据/目标revision并原子写入。
- SQLite在线备份/完整性与恢复测试；工程分层、格式与依赖边界门禁；桌面/移动截图实际检查。

## 明确没有完成或没有外部验证

- 真实LLM provider/key未配置，质量/费用/语义引用支持尚未实测；mock只证明协议和错误路径。
- 邮件验证与密码找回、OIDC、自助注销账号、公开分享/协作、附件、链接反链与完整Markdown包导入导出尚未交付。
- 来源处理为显式同步处理，不是持久异步worker集群；向量/embedding/reranker未做。
- 代码插件沙箱、动态UI插件槽、独立官方插件包/SDK分发未做；当前仅受信静态能力+声明式用户组件。
- 组件/知识存储仍部分混合规则与SQL；App继续持编辑状态，不能声称最终可扩展架构全部落地。
- 全局请求速率、页面历史总量、成本配额与公网运维加固不完整。当前仅单实例本机试运行，不能直接公网部署。
- GitHub Actions配置已写，不代表远程CI运行通过；管理员三角色全流程有API测试但尚无三身份浏览器全过程。

## 验证口径

正式测试不计入已归档自写认证实验。关键命令：pnpm test / build / format:check / test:e2e / audit。最终核查还需再次执行并记录结果；任何一项失败不以其它成功掩盖。截图在artifacts/visual，使用测试账号与内存数据，不包含真实用户私密内容。

## 运行命令

- 管理员：pnpm exec tsx src/admin.ts grant <已注册邮箱>；revoke同理。
- 备份：pnpm exec tsx src/backup.ts <全新备份路径>。同时安全备份宿主auth-secret或部署secret，未来附件也需单独覆盖。
- 恢复：停止服务，先保全当前数据库及WAL/SHM，使用已验证备份作为MEOW_DATABASE启动；不在运行中直接覆盖主数据库。现无一键破坏性恢复命令。
- 模型：部署环境同时设置MEOW_MODEL_ENDPOINT/NAME/KEY；本机HTTP需显式MEOW_MODEL_ALLOW_LOCAL=1；不经UI接受任意endpoint。
