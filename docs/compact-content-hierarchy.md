# 内容优先的跨页层级

用户反馈非Wiki页面描述过多，主体不突出。采用短标题/主要操作优先，使用说明原生details按需展开，减少重复英文眉题与营销性介绍，压缩卡片外层留白，不以缩小正文替代信息整理。

覆盖首页/组件市场与目录/工坊与Provider/实验室/知识域/资料工作台/MCP/提议/审核/工作空间设置。费用、HTTP明文、一次性令牌、私有导入不发布、权限限制与不可逆操作仍就近常显，错误与未配置反馈保留。

不改变业务接口或安全策略。验证：162项默认测试通过；生产构建/类型/格式通过；20个系统spec共21个浏览器测试通过，独立对话式HTTP Provider验收1项通过；新跨页测试验证帮助默认折叠且可键盘展开/收起、移动端无整页横溢。工坊桌面/移动与知识域桌面截图已实际查看。
