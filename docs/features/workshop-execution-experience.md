# 工坊执行工作台与视觉层级

性质：已实施功能。2026-11-12。

用户反馈执行信息不足、框套框拥挤、配色重点弱。目标是宽敞对话工作台：现已升级为左侧对话/执行、右侧预览/源码切换，设置与技术帮助退居次级；旧按需展开预览抽屉已移除。减少独立卡片与重复边框。采用浅中性底、深色正文、深蓝绿主操作；成功/等待/失败既有颜色又有文字，聚焦交互不靠淡绿填充。

工具事件按callId合成执行行，显示真实开始/完成/失败/耗时；展开查看文件路径、UTF8字节/行数、校验结果和经约束的问题列表。不是模型内部思考，不存raw文件/Key/上游响应；记录仍有权限与预算。旧消息无详情时诚实提示，不补造历史执行结果。

执行信息来自服务端真实工具结果，UI展开不授予执行权限。取消、8轮预算、用户明确保存/不自动发布保持原边界。

插件实验室另检查：标准隔离链路可用，示例主动触发的SecurityError/CSP TypeError是保护生效，不是运行失败。界面改中文通过状态、技术名收入诊断；增加连接超时与重连，crypto异常纳入catch。尚未取得用户原报错截图，不能断言已定位其所有具体错误。

## 页面创作首个闭环（实施中）

页面项目使用版本化meow.page/1声明与共享composition契约，从首页/知识空间/协作的已保存布局或空白副本开始；/project/page.json为唯一页面可写文件，SDK只读。Agent与手工编辑写同一项目revision，手工保存和显式应用均CAS；生成/校验/finish不自动应用。应用在事务中检查项目版本和来源页面revision，资源/组件归属由composition服务再次授权，失败保留旧页面。旧组件项目返回shape/安装语义保持兼容。

工作台提供左对话右预览/源码与文件树，预览复用CanvasTree/Frame及共享布局样式，不调用页面保存。业务数据由App授权适配，当前Wiki正文真实读取授权笔记，协作及写入工具栏以明确只读占位展示，不冒称完整业务交互预览。源码目前是JSON配置，不是TSX执行；原生风格包/构建隔离、新导航页面及可安装自定义Agent仍待后续。Agent定义已抽为版本化可信指令，外部项目上下文只以user数据消息传递，不能借项目文件升级system权限。

首批针对性验证：14项页面/会话契约测试通过，旧组件与页面源码→预览→确认应用浏览器通过，独立HTTP Provider对话旧链通过，类型/构建通过；253项默认测试及格式检查通过；尚未重跑全系统矩阵，不外推之前测试数字。界面清理旧预览drawer CSS，提取项目选择、源码、应用操作、左右工作区，删除正式宿主重复布局计算。
