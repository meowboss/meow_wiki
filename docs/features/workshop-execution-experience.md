# 工坊执行工作台与视觉层级

性质：已实施功能。更新2026-11-13。

用户反馈执行信息不足、框套框拥挤、配色重点弱。目标是宽敞对话工作台：现已升级为左侧对话/执行、右侧预览/源码切换，设置与技术帮助退居次级；旧按需展开预览抽屉已移除。减少独立卡片与重复边框。采用浅中性底、深色正文、深蓝绿主操作；成功/等待/失败既有颜色又有文字，聚焦交互不靠淡绿填充。

工具事件按callId合成执行行，显示真实开始/完成/失败/耗时；展开查看文件路径、UTF8字节/行数、校验结果和经约束的问题列表。不是模型内部思考，不存raw文件/Key/上游响应；记录仍有权限与预算。旧消息无详情时诚实提示，不补造历史执行结果。

执行信息来自服务端真实工具结果，UI展开不授予执行权限。取消、用户明确保存/不自动发布保持原边界。原8轮硬限制已取代：对话可继续，真实步骤不clamp；单次运行180秒/128步仅作为异常熔断，连续4次同工具及同结果判无进展，保留单次请求超时及取消。旧数据库CHECK迁移保留列、索引、trigger、修订和消息。界面不把异常保护显示成正常创作总轮数。

插件实验室另检查：标准隔离链路可用，示例主动触发的SecurityError/CSP TypeError是保护生效，不是运行失败。界面改中文通过状态、技术名收入诊断；增加连接超时与重连，crypto异常纳入catch。尚未取得用户原报错截图，不能断言已定位其所有具体错误。

## 全视口创作工作台（2026-11-13后继）

进入工坊默认仅显示专用Agent对话/轨迹、输入栏和可显隐的右工作区；项目类型/页面/已有项目选择收进顶栏文件夹按钮的Modal，不再常驻堆叠。全视口无document纵向滚动，消息/轨迹、预览和源码独立滚动；真实操作反馈以非阻挡toast显示，校验/应用操作收进右工具栏。旧大标题/说明/配置/边界DOM和相应废样式已删除。

桌面中间6px分隔条支持pointer capture拖动30%–70%，方向键±2%、Home/End边界和双击恢复50%；隐藏右区聊天居中扩展，状态不卸载。移动端默认对话单面板，右区为覆盖切换而非上下长页面；顶栏补返回导航按钮。Provider配置迁至个人设置的共享模块，密钥/协议/费用/HTTP与工坊权限说明合并个人使用须知；工坊仅保留已有模型选择，不再呈现Provider表单和零散说明。没有模拟语音按钮、token用量等未实现功能。

本次验证：272项默认测试、类型/构建/格式通过；4个工坊/Provider针对性system spec与2个真实HTTP fixture对话用例通过。全系统串行运行至sidebar用例仅因旧大标题断言退出，更新为工作台region后，剩余及相关9个spec全部通过，覆盖43个spec中的全部用例分段验收；不冒称单次最终全套一次通过。拖动比例/键盘/双击复位、desktop无document滚动、mobile单面板和Provider个人设置入口已验收，截图实际查看。notice曾遮挡toolbar，已移为非阻挡toast并重测。

## 页面创作首个声明式闭环

范围：已实现当前页面/空白项目、对话与源码共享版本、实际画布预览、显式应用或新建导航页及继续编辑；这是原生源码包之前的兼容阶段。不是TSX构建执行，不将后续包系统与可定制Agent运行时写成完成。

页面项目使用版本化meow.page/1声明与共享composition契约，从首页/知识空间/协作的已保存布局或空白副本开始；/project/page.json为唯一页面可写文件，SDK只读。Agent与手工编辑写同一项目revision，手工保存和显式应用均CAS；生成/校验/finish不自动应用。应用在事务中检查项目版本和来源页面revision，资源/组件归属由composition服务再次授权，失败保留旧页面。旧组件项目返回shape/安装语义保持兼容。

工作台提供左对话右预览/源码与文件树，预览复用CanvasTree/Frame及共享布局样式，不调用页面保存。业务数据由App授权适配，当前Wiki正文真实读取授权笔记，协作及写入工具栏以明确只读占位展示，不冒称完整业务交互预览。源码目前是JSON配置，不是TSX执行；原生风格包/构建隔离及可安装自定义Agent仍待后续。页面项目可显式保存为独立创作页面，左侧按当前工作空间列出并打开；快照不写原surface，来源项目+revision唯一避免重复点击创建，50页面/owner限额，素材引用继续保护。独立页可通过“在工坊继续编辑”回到来源项目/对话，目标页模式隐藏旧surface应用，更新时同时检查项目和页面revision；不匹配来源项目禁更新。源码提供懒加载修订记录、线性行号差异摘要及载入历史为草稿，最多保留50条快照，保存/应用与历史同事务，历史不包含凭据。Agent定义已抽为版本化可信指令，外部项目上下文只以user数据消息传递，不能借项目文件升级system权限。
