# Markdown长文空间与阅读改进

用户反馈正文区域小、难阅读。本批针对Wiki页面而非全站组件Markdown：知识空间最大宽度1270→1680、缩小外层装饰留白；长文编辑最低65vh、清晰字号与颜色；阅读模式约80ch行长保持适读，不把整屏拉成长单行。

新增专注模式隐藏导航和空间装饰但保留退出/保存/模式/历史操作，Escape退出仅无dialog时生效；不移动编辑状态所有权，模式切换不保存/丢弃草稿。字号16/18/20可调；原生textarea添加标题/粗体/链接/代码插入，保持选择和焦点，不引入重量编辑器或任意HTML执行。

验证：162项默认测试通过；类型/构建/格式通过；新编辑体验、Markdown安全呈现、Wiki版本历史/恢复3个浏览器spec通过。格式选区插入、专注后实际宽度增大、预览切回草稿完整、Esc退出、小屏无整页横向溢出均有断言；长文桌面专注/移动截图已实际查看，正文可读，编辑工具可达。
