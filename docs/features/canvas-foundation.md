# 页面画布基础增量

性质：实施中的第一批基础能力，不代表完整C0–C2验收。日期2026-11-12。

已接统一composition schema/service/API/CanvasSurface：首页、知识空间、知识域页面各自保存owner/workspace/surface作用域布局，独立revision/强制expectedRevision CAS。GET无写入，旧mw_layouts与release快照不改。首批布局为固定12逻辑列grid、flow、free，提供文本/搜索/当前空间组件实例、位置/尺寸/可见性/颜色/内边距/圆角、拖动与键盘、撤销重做、默认恢复。新实例无强制卡片框。功能视图目录由App可用slot与纯metadata注册表组合，已删除官方视图可逐个加回；恢复默认入口在阅读/编辑模式均可达，需确认且只产生布局草稿，不自动写入。

知识空间目录和阅读/编辑为独立放置实例；首页旧HomeView作为singleton兼容adapter；知识域共享原业务状态，将header、成员域目录和详情作为三个独立画布实例，旧collaboration.content仍可兼容读取。用户的私有/已安装组件可脱离旧首页列表，在各画布独立添加/复制/定位，安装版仍固定releaseId。不是任意代码或动态包registry，也不声称已拆完协作列表/详情等所有业务视图。

草稿边界：业务草稿未保存时禁入布局编辑；编辑态业务子树inert，隐藏保持挂载，legacy业务adapter禁止复制；取消布局不写正文。独立审阅发现过误触/卸载/坐标/专注问题，修复后再做回归。布局请求失败时临时默认业务可用，但未成功读取版本前禁保存；冲突保草稿，显式确认后重载。

媒体增量：图片/视频/桌宠为独立内置视图，可设背景/内容/悬浮层；素材上传、列表、授权读取、单Range视频响应及无引用素材回收已实现，8MiB/文件、32MiB/账号、20个限制。图片格式PNG/JPEG/GIF/WebP、视频MP4/WebM仅校验签名不承诺所有codec；媒体URL仅同源assetId，保存布局时校验归属/MIME。桌宠为emoji内置交互、暂停与减少动效；视频遵守静音自动播放、后台/卸载暂停，不是任意脚本桌宠。背景/overlay需清除网格placement避免二次坐标计算；小屏overlay流式回退。上传/删除busy阻布局保存防绑定丢失。

嵌套增量：可选tree支持行/列/网格容器，创建容器并将实例移入；全实例恰好引用一次、深度6/节点80/子节点40预算，循环与极深JS先迭代拒绝再递归解析。背景/overlay仍独立层单挂，隐藏嵌套实例保留DOM；默认flat旧数据兼容。平面顺序可前后排列，nested坐标键与平面排序禁用，使用容器移动控制避免不可见dirty。创建树与移动会改变React父树，业务草稿须先保存/取消，布局GET期间inert防初载竞态。长实例ID映射短nodeID，删除仅修剪受影响空祖先，不删无关预建空容器。

限制：自由布局高度仍按逻辑网格，嵌套容器尚缺可视拖放重排/容器属性与完整资源保活；动态插件包、跨页常驻、typed事件连线、工坊v2管线；提供“迁移旧首页组件”显式操作，将标题/顺序/引用转换为独立实例；旧JSON/revision不改，迁移marker与新composition同事务，重复迁移不覆盖后续布局。只含已授权组件引用，失效时整次回滚。旧列表仍兼容保留。完整愿景见架构与路线，不能把本批当全站画布完成。

嵌套增量验证：204项默认测试通过；嵌套保存/重载、失败回退与inert、三页面布局排序撤销/重做浏览器复验通过；类型/构建通过，独立审阅5项缺陷已修正并补长ID/空容器回归。媒体增量验证：185项默认测试通过，媒体上传/桌宠/刷新浏览器用例通过，既有完整30个系统spec/31个测试通过后又修复层CSS、busy锁与回收并执行针对性复验；生产构建/类型/格式通过。真实视频codec播放未用真实视频文件验收，Range与暂停生命周期单独验证，不称所有媒体兼容。后续显式迁移增量验证：181项默认测试通过，迁移UI及5个画布浏览器用例通过；类型/构建/格式通过。以下为基础快照：175项默认测试通过，生产构建/类型通过；三页面布局、独立组件复制、失败默认回退与inert、409草稿保留浏览器验收通过；既有系统spec分段通过，目录展开宽度曾回归已修复。协作拆分后canvas/domains/domain-build再次通过。完整验收会随最终快照更新；不将当前基础增量称完整C0–C2。
