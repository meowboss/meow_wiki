# 页面画布基础增量

性质：实施中的第一批基础能力，不代表完整C0–C2验收。日期2026-11-12。

已接统一composition schema/service/API/CanvasSurface：首页、知识空间、知识域页面各自保存owner/workspace/surface作用域布局，独立revision/强制expectedRevision CAS。GET无写入，旧mw_layouts与release快照不改。首批布局为固定12逻辑列grid、flow、free，提供文本/搜索/当前空间组件实例、位置/尺寸/可见性/颜色/内边距/圆角、拖动与键盘、撤销重做、默认恢复。新实例无强制卡片框。功能视图目录由App可用slot与纯metadata注册表组合，已删除官方视图可逐个加回；恢复默认入口在阅读/编辑模式均可达，需确认且只产生布局草稿，不自动写入。

知识空间标题、统计、问答入口、页脚、阅读工具栏、目录和正文分别为独立实例，新正文splitToolbar标记可删工具栏不回生；旧文档无标记保留内嵌工具栏兼容。单Reader状态位于画布上层共享字号/专注，旧布局可恢复默认获取完整新版。首页共享单HomeView状态，将工具栏、组合设置、内容分别放置，新content带splitHome标记，旧content回退内嵌管理界面；显式迁移只产出独立标题/组件，不额外带入新的默认管理视图；知识域共享原业务状态，将header、成员域目录和详情作为三个独立画布实例，旧collaboration.content仍可兼容读取。用户的私有/已安装组件可脱离旧首页列表，在各画布独立添加/复制/定位，安装版仍固定releaseId。不是任意代码或动态包registry，也不声称已拆完协作列表/详情等所有业务视图。

受信注册：App使用不可变renderer注册表分发，不再每个新视图增加switch；official.package.view格式契约允许编译期受信包扩展，metadata无可执行字段，unknown为占位而非执行slot。不是任意用户代码加载。

刷新草稿：sessionStorage按真实owner/workspace/surface隔离保存布局草稿（1MiB），GET后显式恢复/丢弃；旧baseRevision冲突时保留草稿禁止覆盖，save/cancel清当前scope，storage失败不抛、不复制正文/Key。媒体上下文hidden/edit/loading暂停视频与桌宠动效。

草稿边界：业务草稿未保存时禁入布局编辑；编辑态业务子树inert，隐藏保持挂载，legacy业务adapter禁止复制；取消布局不写正文。独立审阅发现过误触/卸载/坐标/专注问题，修复后再做回归。布局请求失败时临时默认业务可用，但未成功读取版本前禁保存；冲突保草稿，显式确认后重载。

媒体增量：图片/视频/桌宠为独立内置视图，可设背景/内容/悬浮层；素材上传、列表、授权读取、单Range视频响应及无引用素材回收已实现，8MiB/文件、32MiB/账号、20个限制。图片格式PNG/JPEG/GIF/WebP、视频MP4/WebM仅校验签名不承诺所有codec；媒体URL仅同源assetId，保存布局时校验归属/MIME。桌宠为emoji内置交互、暂停与减少动效；视频遵守静音自动播放、后台/卸载暂停，不是任意脚本桌宠。背景/overlay需清除网格placement避免二次坐标计算；小屏overlay流式回退。上传/删除busy阻布局保存防绑定丢失。

嵌套增量：可选tree支持行/列/网格容器，创建容器并将实例移入，修改容器间距/网格列数/排列方向、同父叶前移后移；全实例恰好引用一次、深度6/节点80/子节点40预算，循环与极深JS先迭代拒绝再递归解析。背景/overlay仍独立层单挂，隐藏嵌套实例保留DOM；默认flat旧数据兼容。平面顺序可前后排列，nested坐标键与平面排序禁用，使用容器移动控制避免不可见dirty。创建树与移动会改变React父树，业务草稿须先保存/取消，布局GET期间inert防初载竞态。长实例ID映射短nodeID，删除仅修剪受影响空祖先，不删无关预建空容器。

限制：自由布局高度仍按逻辑网格，嵌套容器已有层列表内部拖放入容器，仍缺直接画布拖放重排与完整资源保活；动态插件包、跨页常驻、typed事件连线、工坊v2管线；提供“迁移旧首页组件”显式操作，将标题/顺序/引用转换为独立实例；旧JSON/revision不改，迁移marker与新composition同事务，重复迁移不覆盖后续布局。只含已授权组件引用，失效时整次回滚。旧列表仍兼容保留。完整愿景见架构与路线，不能把本批当全站画布完成。

验收补充：新增纯键盘添加/选择/移动/尺寸/层级/保存链，CSS 200%放大与390px编辑用例通过（不等同浏览器菜单缩放的全部平台矩阵）；真实双标签CAS冲突后草稿刷新恢复仍禁覆盖。迁移直接比较release.content与digest前后字节不变。目录展开仅作用默认4/8布局，不能覆盖用户右置或自定义宽度。

尺寸与对齐增量：平面grid/free编辑态右下手柄支持pointer capture，拖动显示逻辑尺寸，pointerup提交、cancel不写；键盘左右/上下调宽高，边界w<=12-x、h<=24。属性面板提供靠左/居中/靠右/铺满，flow/nested禁用不适用控制。210项默认测试通过，键盘resize+对齐保存重载浏览器用例通过，构建/格式通过；完整34个系统spec/35测试及独立对话验收通过。

层列表拖放与重复目录增量：真实Edge dragTo从组件叶移入新行容器保存/重载通过；两个独立目录实例query互不影响通过，209项默认测试/构建/格式通过。目录为不绑定Markdown的当前授权笔记列表，每实例独立搜索，不等于空间管理树。容器属性增量验证：209项默认测试通过，类型/构建/格式通过；真实浏览器修改方向/间距保存重载、加载期间inert验证通过；390px截图发现目录被正文覆盖，已修flex shrink并补实际boundingBox不重叠断言，修复后桌面移动截图查看通过。嵌套增量验证：204项默认测试通过；嵌套保存/重载、失败回退与inert、三页面布局排序撤销/重做浏览器复验通过；类型/构建通过，独立审阅5项缺陷已修正并补长ID/空容器回归。媒体增量验证：185项默认测试通过，媒体上传/桌宠/刷新浏览器用例通过，既有完整30个系统spec/31个测试通过后又修复层CSS、busy锁与回收并执行针对性复验；生产构建/类型/格式通过。真实视频codec播放未用真实视频文件验收，Range与暂停生命周期单独验证，不称所有媒体兼容。后续显式迁移增量验证：181项默认测试通过，迁移UI及5个画布浏览器用例通过；类型/构建/格式通过。以下为基础快照：175项默认测试通过，生产构建/类型通过；三页面布局、独立组件复制、失败默认回退与inert、409草稿保留浏览器验收通过；既有系统spec分段通过，目录展开宽度曾回归已修复。协作拆分后canvas/domains/domain-build再次通过。完整验收会随最终快照更新；不将当前基础增量称完整C0–C2。
