# 页面画布基础增量

性质：实施中的第一批基础能力，不代表完整C0–C2验收。日期2026-11-12。

已接统一composition schema/service/API/CanvasSurface：首页、知识空间、知识域页面各自保存owner/workspace/surface作用域布局，独立revision/强制expectedRevision CAS。GET无写入，旧mw_layouts与release快照不改。首批布局为固定12逻辑列grid、flow、free，提供文本/搜索/当前空间组件实例、位置/尺寸/可见性/颜色/内边距/圆角、拖动与键盘、撤销重做、默认恢复。新实例无强制卡片框。

知识空间目录和阅读/编辑为独立放置实例；首页旧HomeView作为singleton兼容adapter；知识域共享原业务状态，将header、成员域目录和详情作为三个独立画布实例，旧collaboration.content仍可兼容读取。用户的私有/已安装组件可脱离旧首页列表，在各画布独立添加/复制/定位，安装版仍固定releaseId。不是任意代码或动态包registry，也不声称已拆完协作列表/详情等所有业务视图。

草稿边界：业务草稿未保存时禁入布局编辑；编辑态业务子树inert，隐藏保持挂载，legacy业务adapter禁止复制；取消布局不写正文。独立审阅发现过误触/卸载/坐标/专注问题，修复后再做回归。布局请求失败时临时默认业务可用，但未成功读取版本前禁保存；冲突保草稿，显式确认后重载。

限制：自由布局高度仍按逻辑网格，不具备完整嵌套树/背景层/悬浮层、媒体asset服务、桌宠、用户代码包、typed事件连线、工坊v2管线；尚未显式迁移旧首页为每项独立实例，旧列表兼容保留。完整愿景见架构与路线，不能把本批当全站画布完成。

验证：175项默认测试通过，生产构建/类型通过；三页面布局、独立组件复制、失败默认回退与inert、409草稿保留浏览器验收通过；既有系统spec分段通过，目录展开宽度曾回归已修复。协作拆分后canvas/domains/domain-build再次通过。完整验收会随最终快照更新；不将当前基础增量称完整C0–C2。
